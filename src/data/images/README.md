# Project screenshots

Store PNG, JPG, JPEG, WebP, and SVG screenshots here. Reference filenames relative to this directory in `../projects.txt`, for example `deliserv.png` or `dashboard/overview.webp`, then rebuild. File paths are case-sensitive on GitHub Pages.

The static image import context includes nested folders automatically. Missing or empty image references display the project's placeholder. Keep this README so the directory remains available to the build even if every screenshot is removed.
