Manage skill labels, categories, visibility, ordering, and icon paths in `src/data/skills.json`, then rebuild. Local SVG/PNG paths must start with `/icons/`. HTTP/HTTPS image URLs also work. An empty or omitted icon uses a text tile; an unavailable image falls back to that tile when it fails to load. Local logos avoid a dependency on external image services.
